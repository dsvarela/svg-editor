    Double-click a name to rename it. The name is what the exported id carries.

    Combineneeds 2+

    Shift-click the list to select two or more. The first survives, keeping its name and colour; Subtract takes the rest away from it.

    Draw

    Corner is the radius the rectangle tool draws with, clamped to half the shorter side. Circularise takes a hand-drawn or imported near-circle and makes it exact, keeping every node and rebuilding its handles from the arc each one now spans.

    Nodenone
    Bendno segment

    Select two neighbouring nodes to bend the segment between them. Ctrl+←→ bends, Ctrl+↑↓ loosens.

    Align

    Click a node to edit it. Hollow handles can be pulled out to curve a straight segment.

    Delete

    Fuse keeps the path whole — a pentagon becomes a quadrilateral — but rebuilds one segment out of two, so it approximates. Split leaves two ends and touches no surviving segment at all. Neither is Break here, which keeps the node.

    Transform

    Applies to the selection, or to everything when nothing is selected.
