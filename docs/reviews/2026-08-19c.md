# Review, 2026-08-19c

Covers `6ce398e..6582f70`: the five commits that closed the 97 findings of
[2026-08-19b](2026-08-19b.md). About 1 780 lines across 24 files, none of it read
by anything but its author, and every one of those commits written in the belief
that it was closing a defect class rather than opening one.

**What it found: about 50 findings, of which one class accounts for a third.**
The class is this: **a fix applied to the instance it was reported on and not to
its siblings.** The pass that named "an operation that changes nothing must not
file an undo entry" gave `tryEdit` to Align, Distribute and Space, and left
Round counting corners cut. The pass that named "the message is this editor's,
not the engine's" rewrote one message and walked past four more in the same
file. Every instance below is that shape.

Five read-only lanes, weighted inversely to line count: the wiring surface, the
harness and the tests, the call sites, the wire format, the record.

## The one that loses work

**A negative `stroke-width` made a document this build writes a document this
build cannot read.** `io/svg.ts` imported `stroke-width="-4"` unguarded, and the
guard added to the session *reader* in this range then refused the whole file:

```
read back = the drawing in it is malformed
```

Open any SVG carrying an invalid width, draw for an hour, reload, and the work
is gone. Worse in combination with the other fix in the same commit: an
unreadable session is now kept and the autosave stopped, so the loss repeats
every session until somebody reloads.

The guard was at the wrong end of the pipe, and §59's own justification says so
without noticing: "it reaches `exportSvg` as `stroke-width=\"-4\"`" is an
argument for guarding the import, which is where the value is made. The reader
is not on the path from import to export and could never have prevented what it
was written to prevent. Clamped at import now, with the reader's refusal kept
for a hand-edited file.

## The ceiling that bounded the wrong thing

`PNG_MAX` refused a typed width over 8192 and nothing bounded the height:

```
pngSize({w: 10, h: 10000}, 8192)  ->  { w: 8192, h: 8192000 }   67 109 megapixels
```

against the 300 megapixels the ceiling was written to refuse. The bound was on
the input where the invariant is about the output. Both sides are bounded now,
and a tall document is reduced rather than squashed, so §53's "the PNG cannot be
a differently shaped picture from the canvas" still holds.

## A restore is not an edit

§49's contiguity is restored by `Store.edit` after every edit. `applySession`
goes through `Store.update`, so a workspace file whose shapes interleave two
groups stayed interleaved until some later edit happened to fix it, and
`exportSvg` in between wrote one group as two `<g>` under two ids -- which is
exactly the defect §49 exists to make impossible, reached by the one route that
is not an edit. `pruneGroups` and `rebuildPaintOrder` run on the way in now.

## A preference that reads leniently and then throws

`decimals` restored unbounded. It is a number at any magnitude, so the type
check passed 500, and `formatNumber` is `toFixed`, which throws a `RangeError`
outside 0 to 100. The throw lands one store notification later, inside the
refresh that draws the previews. §59 says lenience is a fallback rather than a
throw; this was a throw arriving by a route §59 did not cover. Bounded to what
the field offers. Pre-existing, not from this range.

## Checks that could not fail, in the pass whose subject was checks that could not fail

Five, of which three were proved by mutation rather than by argument.

**`test/identity.test.ts`, "mints an id the document does not already hold".**
`idSeq` is a module global that every earlier test in the file has advanced, so a
document holding `shape-1` cannot collide with a fresh mint however wrong the
order is. Making `reserveIds` a no-op left it green. It asks the counter where it
is and plants that id now, which is the only form of it that can go red.

**`test/storage.test.ts`, "is cleared with the session it was about".** Written
as forget-then-save-then-load, and a successful write clears the marker itself:
deleting `removeItem(STALE)` from `forget()` left the whole suite green. It reads
storage directly after the `forget`, with no write in between.

**`test/controller.test.ts`, "measures the room a corner has".** Its comment says
the live-path limit on that fixture is 16. It is **0** -- every node of a fully
rounded square reports `curved`, so `if (fits > 0)` never fires and the radius is
unclamped either way. The test went red before the fix, but for the reason the
test above it already covers. The number 16 was invented, in the test and in §48.

**`combine`'s subtract.** Both operands are 20 by 20, so A−B and B−A enclose the
same area and neither block reads the geometry. Reversing the documented
first-minus-the-rest rule leaves every check green.

**`zorder`'s four-pixel drag** sat exactly on the slop boundary: `ROW_SLOP` is 4
and the guard is `< ROW_SLOP`. Raise the slop by one, or have a move coalesce,
and the press never becomes a drag -- at which point both assertions pass with
the defect fully restored. Ten pixels, with margin on both sides.

And **`session`'s "the bytes survived" had no precondition** that anything ever
tried to overwrite them: if the rectangle failed to draw, nothing notified,
nothing was scheduled, and the flush on the way out wrote nothing.

## The gate that measured a fifth of what it claimed

The audit's NaN sweep was widened in this range from `.artwork path`'s `d` to
sixteen attributes. It still missed the two that matter most:

- **`viewBox`**, written on both SVG roots from raw template interpolation. A

## The importer's warning fired when nothing was lost

`fill-opacity="1"` reported a loss. So did `1.0`, `100%`, `1.5`, `inherit`, an
empty value, and whitespace -- and every one of `<defs>`, `<mask>`, the root

value below full, on an element that becomes a shape.

## The three gaps, closed the same day

The section above names three things this review did not do. All three are done
here, and each found something.

### `tools/drive.mjs`, read whole

607 lines had changed in the range and the lane read the new checks rather than
the file. Two defects, neither of them in the new checks.

- **The value after a flag was taken as the scenario name.** `--out shot.png
  smoke` read `shot.png` as the scenario and ran nothing. `tools/mutate.mjs`
  keeps a `flagValues` set for exactly this, under the comment "The value that
  follows a flag is not a target" -- so this is this review's own dominant class
  one tool over: fixed on the instance it was found on, not on its sibling. The
  documented argument order works, which is why nobody had met it.
- **`attribute(s)`** in the exit message. `check:docs` does not sweep `tools/`,
  so nothing catches a plural the writing rules refuse.

### The mutation tester, run

170 sites over the five changed files a unit test can reach, 29 survivors.

**Two of the survivors were the tester's own noise, and closing that took the
same five files from 170 sites to 129.**

- **The `<` and `>` of a type argument are mutation sites, and none of them can
  ever be a finding.** `new Promise<Blob>` mutated to `Promise<=Blob>` is not
  the syntax error it looks like: esbuild reads it as
  `new Promise() <= Blob > (…)`, which parses, so the file loads and nothing
  observable changes. 262 of the 804 angle brackets in `src/` are type
  arguments. They are paired by a scan now, because only pairing tells
  `Map<string, Pt[]>` from `a < b && c > d`.
- **A comment was judged one line at a time**, so a wrapped block-comment line
  starting with anything but `*` read as code. `src/io/session.ts:204` begins
  with a backtick and was reported as a survivor. Tracked across lines now.

**Six more were `det` and `invert` in `src/core/affine.ts`, which nothing
calls.** `det` is used only by `invert`, and `invert` is imported by nothing in
`src/`, `test/` or `tools/`. `code` rule 13, and the answer to it is deletion:
git holds them if they are ever wanted. That is six survivors retired by
removing the code rather than by testing it.

**Four moved something. Each has a test that was broken and watched go red:**

| Survivor | What it was |
|---|---|
| `mul`'s first cross term | **A sign flip passed all 1 110 tests.** `about` is translate, matrix, translate, so one side of every product it forms is axis-aligned, and no fixture composed two turns |
| `flipY` | **Returning the identity passed all 1 110 tests.** Flip vertical had no test at all; flip horizontal had two. The half-a-pair class again |
| the dedupe in `selectedNodes` | no test mentioned it, and none mentioned `alignNodes` or `distributeNodes` beside it |
| the session's size limit | tested at `LIMIT + 1` and never at `LIMIT`, so `>` widened to `>=` refused a drawing exactly at the bound and lost it |

**Seven are boundary-only.** `isIdentity`'s six tolerances and `groupChain`'s
cycle guard differ between `<` and `<=` only for a value sitting exactly on the
bound, or for a document with a parent cycle, which is a wrong list either way.
Read and left.

**Seven are in `src/io/session.ts`, and they are one class**: a validator that
refuses on any one of several bad fields, tested only ever with the *last*
disjunct bad. Killing `A || B` needs exactly one side true, so every earlier
field in each guard is unmeasured. Two of the seven are closed here because
they lose work:

- **A group's parent was discarded.** `g.parent && !known.has(g.parent)` is only
  measured by a parent that IS known, and the one group test was flat. Widened
  to a disjunction, every real parent is cleared and nesting made anywhere is
  lost on the way in.
- **`1e999` is a legal JSON number that parses to `Infinity`.** `typeof v ===
  'number'` admits it and only `Number.isFinite` turns it away, and nothing
  measured that half. An infinite coordinate reaches the `d` attribute, which
  the browser harness sweeps for one step later.

**The other five were closed the same day, and the class is worth stating
plainly.** A guard reading `A || B || C` is only measured by a fixture where
exactly one of the three is true. Every refusal test in this file happened to
spoil the *last* field of the guard it exercised, so with the earlier fields all
good the guard answers on the last one alone and the rest go unchecked. That is
what left `readStyle`'s `fill` and `stroke`, `readShape`'s `id`, and
`readPolygon`'s `corners` and `ratio` untested: five fields of a wire format,
each one bad field away from being read.

The group-parent walk in `pruneGroups` needed no new fixture. The nested-group
test above already kills it: with `o.id === at` inverted, the walk climbs to
whichever group is not the one it is looking for, decides it has found a cycle,
and roots the group.

`src/io/session.ts` now survives **0 of 62** mutations against
`test/session.test.ts`.

**The tester also left a hung run behind.** `spawnSync`'s timeout signals the
process it started, and through `npx` that is `npx`: it dies, vitest below it is
orphaned, and its fork workers keep going. One `vitest related` run was still
holding two cores 26 minutes after its 180-second timeout. The browser sweep
that followed failed `traceWorker` on its responsiveness bound and passed on a
quiet machine, **so that red said nothing about the code** -- the fifth time a
signal in this project has been worth nothing, and the second that was a red.
The local binary is spawned directly now, so the signal reaches vitest and it
tears its own pool down.

## Correction, added 2026-08-20

**This file contradicts itself about its own work, and the later sentence is
the wrong one.** "What this did not do" ends with *"the five filed session
guards above are filed, not fixed"*. Two sections earlier the same file says
*"The other five were closed the same day"* and gives the argument, and the
paragraph after that reports `src/io/session.ts` surviving 0 of 62 mutations
against `test/session.test.ts`, which it could not do with five guards
unmeasured.

The tests are there and were read on 2026-08-20 before this note was written:
`test/session.test.ts:228` refuses a shape id that is not a string,
`:253` and `:259` refuse a fill and a stroke that are not strings, and `:512`
falls back for a polygon whose `corners` or `ratio` is not a number. Those are
the five.

The closing sentence was written from the plan rather than from the tree: the
five were filed when the section above them was drafted and closed before the
section below them was. Both halves of the file are left exactly as they were,
per this directory's rule. **What it should have said is that all seven of the
`session.ts` guards were closed, and that what this review did not do was the
mutation sweep of `src/main.ts`, `src/tools/` and `src/view/`** -- which is the
other half of the same sentence, and which was still true until 2026-08-20.
