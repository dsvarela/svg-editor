## The five that changed or destroyed what somebody made

**`groupSelection` broke the invariant `CLAUDE.md` named it as the guardian of.**
Group three shapes, then group a loose shape with one from the middle of that
group: the first group is left in two runs, and `exportSvg` writes it as two
`<g>` elements under two different ids, because `uniqueXmlId` renames the
second. Export and re-import turns two groups into three. Fixed by making
`Store.edit` and `tryEdit` restore contiguity after every edit, so a broken run
is a state the document cannot be left in.

**`flattenOrders` silently deleted shapes.** It walked from the root and returned
only what it reached, so a shape under a group whose `parent` named nothing sat
in the map under a key nothing visited. `[s0 s1 s2] -> [s2 s1]`, with the reorder
reporting success. Reachable from a workspace file, because `readGroup` took any
string as a parent and `applySession` installs it with `update`, which does not
prune. Fixed at both ends: the walk is total, and the reader roots a dangling
parent and breaks a cycle.

**Opacity exported as `opacity="0"`.** It was rounded with the serialiser's
`decimals`, which is offered from 0 and described to the reader as trading file
size against a coarser shape. At 0 decimals every shape below half opacity was
invisible in the saved file. A shape that vanishes is not a coarser shape.

**A typed size landed on the shape you clicked next.** The selection box commits
on `change`, `change` fires on blur, and moving focus is the *default action* of
a pointerdown, so it runs after every pointerdown listener. Type 50 into the
width, press a different shape, and that shape is resized mid-gesture while the
one the field described is untouched.

**A dropped row went to the end of the paint order.** `dropShapes` looks its
`before` key up among the rows that are staying; the caller passed the row at the
gap whether or not it was one of the rows being dragged.

## What this says about the tests

Twelve checks in `tools/drive.mjs` hold on state a previous step had already
produced. Five were proved by breaking a copy of the tree and re-running:
`zorder`'s row-drag destination, `undoFromField` twice, `arrange`'s empty-Gap
branch, and `png`'s four previews. `png` asked whether the preview URI contained
`#2563d8` -- which is `defaultStyle().stroke`, so it is in every drawing this
editor makes.

**Three of my own tests could not fail on first writing**, in this session:
a guide fixture that refused whether or not the guard was there, an angle origin
that read back the same either way, and a browser check whose output was
byte-identical with the fix and without it. The third was deleted rather than
kept. A fourth was wrong in the other direction: it counted a group's direct
members, which calls correct nesting a break, and it failed against code that was
right.

The lesson is not "write better tests". It is that **the only thing that
distinguishes a test from a decoration is watching it go red**, and that holds for
the person who has spent all day finding checks that cannot fail.

### Open: the wire format

- **An unreadable session is deleted**, and the stated reason is false. `read`
  returns a sentence, `main.ts` calls `sessions.forget()`, and the comment says
  otherwise it would refuse the same file on every load and never save over it.
  The autosave subscriber is unconditional, so the first edit overwrites it
  anyway. Bump `SESSION_VERSION` and a newer session is erased by an older
  build before a pixel is on screen.
- **An autosave refused for size leaves the previous copy in place**, and the
  next load announces it as "Picked up where you left off" -- a different
  drawing from the one that was on screen, with a sentence asserting it is not.
- **`Style.opacity` reads leniently inside a document that reads strictly.**
  `"0.25"` as a string restores as fully opaque with no message, where a string
  `strokeWidth` on the line above refuses the whole file.
- **`strokeWidth` accepts any finite number, including negative**, which reaches
  `exportSvg` as `stroke-width="-4"`. The reader is the only guard there is.
- **`fill-opacity` and `stroke-opacity` are dropped silently** next to a
  `warnings` channel that already reports three other things it drops. A fill
  going from 30% to 100% is not visible as a loss, only as a wrong picture.

*Closed in this pass: opacity export precision, the workspace backdrop, the
dangling and cyclic group parents, Repeat's stale matrix.*

### Open: the interface

  defect that was fixed. It needs somebody to instrument `aimRowDrag`.
- **Opening Preview renders nothing** until an unrelated notification arrives:
  its catch-up listener is registered before the collapse listener, so it reads
  `aria-expanded` from before the press. Shutting it renders instead.
- **`previewOpen()` does not ask whether its tab is on screen**, so every
  notification re-serialises the whole document into four data URIs while the
  Preview group sits inside a hidden panel.
- **The shape list is `role="tree"` with no roving tabindex, no
  `aria-activedescendant` and no `id` on any row**, so a screen reader announces
  nothing as the selection walks it. `tools/keys.mjs` cannot see this: every row
  is reachable, just unannounced. This is the most serious of the open interface
  items.
- **`#selW` and `#selH` offer `min="0"`**, a value `setSelectionBound` refuses.
- **`#pngWidth`'s `max="8192"` is decorative**: a typed 20000 renders a
  291-megapixel canvas.
- **The PNG failure path prints the browser's own exception text** into a status
  line `docs/STYLE.md` governs, and the message differs by engine.
- **`.ghelp[aria-expanded]` outranks the coarse-pointer block**, so a pressed

- A group row and its `.twist` both carry `aria-expanded`, announcing it twice;

*Closed: the typed size landing on the wrong shape, the 22 stale controls, the

### Open: the model and its call sites

- **A scale drag remembers the unsnapped matrix.** The move handler snaps the
  delta before building it; the release handler rebuilds from the raw pointer.
  Drag a 10x10 square 2.4 units with grid snap on: the document scales 1.2 and
  Repeat scales 1.24, compounding on every press.
- **A bare click on a scale or rotate grip records an identity matrix**, which
  destroys whatever Repeat was holding. The `body` branch guards on a non-zero
  delta; this one does not.
- **The Round button cannot change a radius the Round drag can.** The drag runs
  `unroundCorner` first; `roundSelection` goes straight to `roundCorner`, which
  refuses curved sides. On a rounded rectangle the radius field is dead.
- **Align, distribute and space use `store.edit`**, so pressing Align Left three
  times files three history entries, two of them empty. `reorderSelection`
  argues the opposite case and uses `tryEdit`.
- **Dragging a row inside a fully selected group is a silent no-op**: the drop
  line follows the pointer and nothing happens on release.
- **`readDoc` still does not check §46.** Two nodes sharing an id are accepted
  from a workspace file. The §49 half was closed.
- **`#selectGroup` and `#repeatTransform` have no `busy` guard**, while their
  keys do and the comment names the hazard.
- `canGroup` counts selection ids where `groupSelection` counts live shapes;
  divergence confirmed by fixture, no reachable route found.
- `canSplitShapes()` is a method where every other capability probe is a getter.
- `remember`'s docstring says it runs after the gesture's batch closed; it runs
  before. No behavioural consequence, wrong reason given.

*Closed: `groupSelection` contiguity, `flattenOrders` totality, the drop key,

## Closed, 2026-08-19, by the pass that followed

Everything listed above as open is fixed, in five commits. **The list is left
exactly as it was written**, per this directory's rule: what each finding said on
the day is the evidence, and this section is what happened to it.

Six of them turned out to be a different defect from the one recorded, and those
are the ones worth reading.

**The four-pixel row drag had two causes, and either alone would have kept it.**
The walk that steps past a travelling row was already written and did nothing: it
read the `lifted` class from rows the same function had cleared four lines above.
And `dropShapes` answered a `before` it could not place with the end of the list,
which is the front of the paint order. Both are fixed, because the caller
reaching that case is not something to rely on staying true.

**`undoFromField`'s headline check was not on an empty stack.** Breaking the
guard turns it red. The other half of that finding was right: its clipboard block
ran with one node selected, and `copySelection` refuses a lone node, so both keys
were no-ops whichever way they routed.

**`combine`'s enclosed-area check could not fail for a reason the finding did not
name.** The fixture was drawn nonzero, and two overlapping contours already
render as their union, so the area after Unite was the area before it. Even-odd
separates them. Exclude still cannot be separated by area, and cannot be in
principle: even-odd rendering of two overlapping contours **is** the symmetric
difference. That is written beside the check now rather than left to look like
the other three.

**Two of the seven uncompared status strings did not say what the fixing pass
predicted**, which is the argument for comparing them stated as cheaply as it can
be.

**A row drag inside a wholly selected group was not a defect in `dropShapes`.**
Every sibling in that group's own list is travelling, so there is nothing left
for them to travel past, and the decline was right. What was wrong was the drop
line, which had followed the pointer the whole way and promised a move no
position could produce. The gesture is refused before the line is drawn.

**Opening Preview was fixed with a second finding folded in.** The listener race
was as recorded. Underneath it, `previewOpen` asked the group whether it was open
and never whether it was on screen, so the same question now covers both.

Two were closed by decision rather than by code:

- **`docs/reviews/2026-08-18b.md` still cites `633ec47`.** The commit it means is
  `378a572`. Left as written, because this directory does not edit a record into
  agreement with the present, and the correction is above.
- **`#pngWidth`'s ceiling is refused, not clamped.** Drawing a smaller PNG than
  the one asked for is the answer that leaves somebody wondering why. Verified
  the hard way: with the guard disabled the browser lost the page mid-scenario.

**What this pass did not do.** It did not re-review the code it changed. Five
commits of fixes across fourteen files have had no adversarial read of their own,
which is the same gap this wrap-up was written to close, one wave later.
