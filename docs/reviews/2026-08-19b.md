## The five that changed or destroyed what somebody made

**`groupSelection` broke the invariant `CLAUDE.md` named it as the guardian of.**
Group three shapes, then group a loose shape with one from the middle of that
group: the first group is left in two runs, and `exportSvg` writes it as two
`<g>` elements under two different ids, because `uniqueXmlId` renames the
second. Export and re-import turns two groups into three. Fixed by making
`Store.edit` and `tryEdit` restore contiguity after every edit, so a broken run
is a state the document cannot be left in.

**`flattenOrders` silently deleted shapes.** It walked from the root and returned
only what it reached, so a shape under a group whose `parent` named nothing sat
in the map under a key nothing visited. `[s0 s1 s2] -> [s2 s1]`, with the reorder
reporting success. Reachable from a workspace file, because `readGroup` took any
string as a parent and `applySession` installs it with `update`, which does not
prune. Fixed at both ends: the walk is total, and the reader roots a dangling
parent and breaks a cycle.

**Opacity exported as `opacity="0"`.** It was rounded with the serialiser's
`decimals`, which is offered from 0 and described to the reader as trading file
size against a coarser shape. At 0 decimals every shape below half opacity was
invisible in the saved file. A shape that vanishes is not a coarser shape.

**A typed size landed on the shape you clicked next.** The selection box commits
on `change`, `change` fires on blur, and moving focus is the *default action* of
a pointerdown, so it runs after every pointerdown listener. Type 50 into the
width, press a different shape, and that shape is resized mid-gesture while the
one the field described is untouched.

**A dropped row went to the end of the paint order.** `dropShapes` looks its
`before` key up among the rows that are staying; the caller passed the row at the
gap whether or not it was one of the rows being dragged.

## What this says about the tests

Twelve checks in `tools/drive.mjs` hold on state a previous step had already
produced. Five were proved by breaking a copy of the tree and re-running:
`zorder`'s row-drag destination, `undoFromField` twice, `arrange`'s empty-Gap
branch, and `png`'s four previews. `png` asked whether the preview URI contained
`#2563d8` -- which is `defaultStyle().stroke`, so it is in every drawing this
editor makes.

**Three of my own tests could not fail on first writing**, in this session:
a guide fixture that refused whether or not the guard was there, an angle origin
that read back the same either way, and a browser check whose output was
byte-identical with the fix and without it. The third was deleted rather than
kept. A fourth was wrong in the other direction: it counted a group's direct
members, which calls correct nesting a break, and it failed against code that was
right.

The lesson is not "write better tests". It is that **the only thing that
distinguishes a test from a decoration is watching it go red**, and that holds for
the person who has spent all day finding checks that cannot fail.

## What was found and not fixed

Filed rather than closed, in priority order:

- **A four-pixel row drag moves a row to the front of a three-row list**,
  before and after the `dropShapes` caller fix alike. Observed, unexplained, and
  not the defect that was fixed. It needs somebody to instrument `aimRowDrag`.
- **Ten of the twelve checks that cannot fail**, listed above. Two were fixed.
- **`badD` in the audit reads only `.artwork path`**, so a NaN reaching overlay
  geometry -- the corner widget, the transform box, the smart guides -- is
  reported by nothing.
- **Seven status strings captured into a scenario's returned blob and never
  compared**, including the selection box's width-0 refusal.
- **The shape list is `role="tree"` with no roving tabindex and no
  `aria-activedescendant`**, so a screen reader announces nothing as the
  selection walks it. `tools/keys.mjs` cannot see this: every row is reachable,
  just unannounced.
- **`#pngWidth`'s `max="8192"` is decorative**; a typed 20000 produces a
  291-megapixel canvas.
- **The PNG failure path prints the browser's own exception text** into a status
  line `docs/STYLE.md` governs.
- **Opening Preview renders nothing** until an unrelated notification arrives:
  its catch-up listener is registered before the collapse listener, so it reads
  `aria-expanded` from before the press.
